# Otterin Connector 0.1.9.0

What's new
- Approving a new iPhone works on the first try and shows a clear "iPhone paired" message.
- Paired iPhones show as cards with View sessions, Send prompts, Start sessions and Revoke.
- Stop, Auto-approve and Refresh speed work from the iPhone app.
- You can open a session and tap Stop while Devin is still working.
- Steps cut off by Stop show "Interrupted" instead of "Failed".
- The Connector now uses the Otterin name in its text.
