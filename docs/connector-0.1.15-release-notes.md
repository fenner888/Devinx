# Otterin Connector 0.1.15 — Otterin rebrand

## Changed
- Renamed the Mac app to Otterin Connector and updated its icon to the Otterin otter; no behavior changes.
- Existing pairing and permissions are preserved.

## Includes
- 0.1.14: Large Devin model catalogs (800+ models) now fit the phone's reply limit, so workspaces and models load again on Home.
- 0.1.13: Reads Devin for Terminal session databases at schema 18 and 19 (Devin 3000.11.x) and databases larger than 2 GB, so workspaces, models and history load again.

## Install
1. Choose Quit DevinX Connector from the menu-bar menu.
2. Open the DMG and drag Otterin Connector into Applications.
3. Move the old "DevinX Connector" app to the Trash.
4. Open Otterin Connector.
5. If it was enabled before, turn "Open Otterin Connector when I log in" back on.

Apple Silicon macOS 13 or newer. Developer ID signed, Apple notarized and stapled.
