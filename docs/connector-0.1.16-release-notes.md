# Otterin Connector 0.1.16 — Local controls

## Changed
- Stop a running turn from your iPhone; auto-approve mode.
- Pairing and local permissions are preserved.

## Install
1. Choose Quit Otterin Connector from the menu-bar menu.
2. Open the DMG and drag Otterin Connector into Applications.
3. Replace the existing Otterin Connector app when prompted.
4. Open Otterin Connector.

Apple Silicon macOS 13 or newer. Developer ID signed, Apple notarized and stapled.
